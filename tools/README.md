# FFmpeg (opcional per a la demostració)

Situa aquí `ffmpeg.exe` i `ffprobe.exe`, procedents d'una distribució de confiança, o afegeix-los al PATH de Windows. Reinicia l'aplicació després d'instal·lar-los. No s'inclouen binaris ni es descarreguen automàticament.

Fonts: https://ffmpeg.org/download.html i https://ffmpeg.org/legal.html

Abans de redistribuir-los, cal revisar la llicència de la compilació escollida. El catàleg els executa amb una llista d'arguments, sense shell, i només escriu miniatures a la seva carpeta de dades.
