# Contribuir a Memòria

Python 3.10 o posterior. No cal instal·lar dependències Python.

Executa `python -m unittest discover -s tests -v` i comprova JavaScript amb `Get-Content -Raw -Encoding UTF8 web/app.js | node --check`.

Utilitza directoris temporals i vídeos sintètics per provar canvis. No incorporis vídeos, miniatures, bases de dades, exportacions, rutes personals ni credencials als commits. No modifiquis originals. Les migracions han de conservar identificadors i anotacions i fer còpia prèvia.

Explica el problema, el canvi i les comprovacions a cada proposta. El servidor és només local; no exposar-lo a xarxa.
